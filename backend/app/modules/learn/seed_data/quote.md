## 한마디로

호가는 "이 가격이면 사겠다" 또는 "이 가격이면 팔겠다"고 부르는 가격이에요. 사려는 가격은 **매수호가**, 팔려는 가격은 **매도호가**라고 하고, 이 가격들을 모아 보여 주는 화면을 **호가창**이라고 해요.

## 비유로 이해하기

벼룩시장에서 파는 사람은 "이 인형 5,000원이요"라고 부르고, 사는 사람은 "4,500원이면 살게요"라고 불러요. 두 사람이 부르는 가격이 맞아떨어지면 거래가 이뤄져요. 주식시장에서도 매수호가와 매도호가가 만나야 거래(체결)가 돼요.

## 숫자 예시

호가창에 이렇게 보인다고 해 볼게요.

| 매도호가 | 매도 수량 | 매수호가 | 매수 수량 |
| --- | --- | --- | --- |
| 10,100원 | 300주 | | |
| | | 10,000원 | 500주 |

지금 바로 사려면 10,100원에 사야 하고, 지금 바로 팔려면 10,000원에 팔아야 해요. 두 가격 사이의 차이를 **호가 차이(스프레드)** 라고 해요.

## 알아둘 점

- 주가가 한 번에 움직일 수 있는 최소 단위(호가 단위)는 가격대에 따라 거래소가 정해요.
- 거래가 적은 종목은 호가 사이의 차이가 큰 경우가 많아서, 생각보다 불리한 가격에 거래될 수 있어요.
